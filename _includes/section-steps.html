{%- comment -%} Section buttons, bottom right on every page: back to the top, previous section, next section. Sections are the page's main headings and anything marked data-step, found by assets/js/site.js, which also names each button after where it goes ("Next section: About the exhibition") and shows that name beside it on hover or focus. Each step moves focus to the section, so keyboard and screen reader users follow. Shift+Up also goes to the top. At the end of the page so these are the last Tab stops; hidden without JavaScript, or on a page with only one section. Icons: Lucide arrow-up-to-line, chevron-up, chevron-down (see NOTICE.md). {%- endcomment %}
